# 任务书 · 施工人物与运营旅客完善（可拆解为 2 个分支任务）

> 目标：在既有 `web/mods/actors.js` 基础上，让工地作业人员和开通后的旅客都具备真实的工序语义与建筑尺度感，告别「随机贴点」。

## 分支任务 W1 · 施工工人姿态、着装与工序强度联动（绿档）
- **目标文件**：`web/mods/actors.js`、`tools/hz/check_actors.js`
- **内容**：
  - 细化墨线/实景双模式下的工人比例与着装区分（安全帽配色区分土建/钢构/吊装指挥、反光背心轮廓）。
  - 扩充姿态并与当前活跃 `HZ.acts` 严格绑定：基础期测量/绑筋、承轨层振捣、屋盖拼装期电焊（带微弱焊花脉冲）、液压提升期千斤顶旁监测与对讲指挥。
  - ~~按镜头距离分档 LOD（`< 140 m` 显示完整姿态，`140–240 m` 简化剪影，`> 240 m` 隐藏）~~（已作废，见下）。
- **验收**：`node tools/hz/check_actors.js` 0 悬空、0 穿模、每帧 `update < 2 ms`；提供 4 种工序近景实拍图。

- **2026-11-23 补充（委托方确认）· 胎架林人物**：为影片 F2 的「胎架林」镜头布置人物，时间 `t = 640–662`，南区胎架林内，沿无人机低空航线两侧（距航线 3–15 m）安排千斤顶旁监测、对讲指挥、仰头观察等姿态，人数要能在 1280×720 画面里一眼看出人和胎架、屋盖的尺度对比。脚底落在实际地坪，不穿胎架。验收时提供 t=640、650、662 各一张与 F2 航线同机位的截图。
- **LOD 以现行代码为准（委托方授权 Hark 决定，2026-11-23）**：`R_SHOW = 120`（镜头 120 m 外不显示），`< 34 m` 启用精细姿态。上文「`< 140 m` / `140–240 m` / `> 240 m`」一条作废。理由：胎架林镜头里的人物都在 15 m 以内，用不到远档；同时可以守住 `update < 2 ms` 的预算。众人开工（⑤）改为低飞拍摄，不靠远处剪影。
