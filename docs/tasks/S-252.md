# 任务书 · S-252 屋盖分区提升（中活）

接 S-251（网架拼装）：三区网架拼好后，按实录顺序 **南 → 中 → 北** 逐区「脱胎」——先整体顶起 0.6 m 离开胎架；南、北两区再绕外缘转 4°（内边抬起 `HZ.innerDrop`），为后面的嵌补合龙与整体提升对齐。插件 `web/sheets/s252.js`，检查 `tools/hz/check_s252.js`。照 `docs/tasks/linkage-v2.md`（parts 联动）与 `docs/BRIEF.md`（墨线、一屏、一个大数字）。宿主接线（`hzwest.html` 加载、`SHEETS_ALL`、图册登记、check_all）由 hark-cr 做。

## 一、时间窗与数据（全部从 HZ 读，不写死）
- 时间窗 `window: [K.lift1.start, K.lift3.end]`。11-08 屋盖排程校准后为第 **636–649** 天（2021-06-14 → 06-27）；提议时写的 632–645 已过时。**不要在插件里写这些数字**，用 `HZ.K.lift1/2/3.start/end`。
- 分区姿态：`HZ.pose(t)[z] = { dy, r, moving }`（z = 1 南 / 2 中 / 3 北）；`dy + HZ.D` = 已顶起高度，`r` = 转角进度 0..1（转角 = `4° × r`，`HZ.P.alpha`），中区 r 恒为 1（只顶升不转）。
- 千斤顶读数：`HZ.jackRead(t)` → `{ rows:[{ i, x, z, zone, top, hp, y, disp, dev, on }], act, m, sync, limit }`：`disp` 行程（m）、`dev` 同步偏差（mm，推算）、`on` 本段是否在动、`sync / limit` 当前最大同步差 / 限值。
- 吊点载荷：`HZ.jackLoad(t)` → `{ rows:[每台 t], total, max }`（11-08 新增，推算：分区钢重按本区吊点平均分摊）。可选用。
- 吊点位置：`HZ.lifters[i] = { x, z, top, zone }`，共 32 台。公开资料写「206 台液压同步提升设备」（二手来源，见 CLAIMS 接口请求「屋盖排程校准」行），模型按吊点（提升架）建，一个吊点含多台提升器——图上若写 206，注明口径。
