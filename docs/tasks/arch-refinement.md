# 任务书 · 建筑本体细化专题（可拆解为 3 个分支任务）

> 目标：在保持 `HZ.make()` 规则排程与 `check_all` 25/25 零违例的前提下，提升远、中、近三档建筑本体表现力，同时直接服务于交互短片的室内穿越机与结尾黄昏镜头。

## 分支任务 A1 · 云门造型与实景幕墙精修（绿档）
- **目标文件**：`web/mods/yunmen.js`
- **内容**：
  - 在 `lit`（实景）模式下以建筑化实体模型替换简模灰盒：四面 Low-E 玻璃幕墙、良渚玉琮韵律香槟铝竖梃与横向腰线、门洞古铜色包边与格栅吊顶、黄昏暖光内透。
  - 在 `S-000` 总图实景/开通后期（`t >= OPEN - 10` 或实景混合 `blend > 0.35`）自动隐藏 `云门 · 示意` 精灵标牌，避免遮挡结尾英雄镜头。
- **验收**：通过 `node tools/hz/check_yunmen.js` 与 `check_all.js`；提交 `t = 1101`、`t = 1120` 远近景及 `S-501 t = 1125` 实景截图。

## 分支任务 A2 · 云厅室内与十字天窗细部（绿档/黄档）
- **目标文件**：新增 `web/mods/interior.js`（绿档模块，按镜头距离 < 180 m 显隐）
- **内容**：为 24 m 候车「云厅」与 28 m 宽「云谷」补充近景建筑构件——检票闸机岛与候车座椅排布示意、5F 空中连廊玻璃护栏与扶梯筒体、24 根梭形柱顶部锥形柱头与十字采光顶主次桁架细部。
- **验收**：严禁穿楼板与侵占云谷净空（`|z| < 14` 保持贯通），室内穿越机视角下空间尺度清晰，每帧 `update < 1.5 ms`。

## 分支任务 A3 · 四角上盖综合体与站台雨棚立面优化（绿档/黄档）
- **目标文件**：`web/mods/tod-detail.js`（或提案后并入 `hzseq.js`）
- **内容**：细化四角上盖开发体块的幕墙分格、退台屋顶与夜间暖色窗格发光；补充站台雨棚柱头与边缘收口、地面层落客高架匝道衔接示意。
- **验收**：不破坏 `A2 穿模 = 0` 与 `R9 塔吊回转净空 = 0` 审计项；提供墨线与实景双模式对比图。
