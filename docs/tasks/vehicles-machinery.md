# 任务书 · 施工车辆、吊装机械与列车运行完善（可拆解为 3 个分支任务）

> 目标：完善工地车辆动态路线、吊装机械动作联动以及开通后多股道列车运行，让施工推演和短片镜头都更具工程真实感。

## 分支任务 V1 · 施工车辆动态行驶路线与姿态贴合（绿档）
- **目标文件**：`web/mods/actors.js`
- **内容**：
  - 为混凝土罐车、渣土自卸车、钢构平板运输车建立基于施工阶段的分段闭环行驶路径（进场通道 → 作业面停靠卸料 → 驶离），车头朝向按切线平滑插值，车轮贴地。
  - 严格避开基坑开挖区、云谷开口（`|z| < 14`）及已建承台柱网，杜绝车体穿模或悬空。
- **验收**：`check_actors.js` 零穿模、零悬空；提供基坑出土期与承轨层浇筑期两张车流轨迹截图。

## 分支任务 V2 · 塔吊与履带吊动作同步及夜间警示（绿档）
- **目标文件**：`web/mods/actors.js`（或 `web/mods/cranes-anim.js`）
- **内容**：
  - 将塔吊回转、小车变幅、吊钩升降与当前正在落位构件的 `sweep` 时刻做真实联动（钩头对准构件中心，不空转）。
  - 补充黄昏/夜景模式下的塔顶航空障碍红灯微闪与吊臂作业探照光效，保证墨线/实景双模式一致。
- **验收**：不触发 `R9 塔吊回转净空` 冲突；提供 S-201 与 S-251 吊装瞬间近景截图。

## 分支任务 V3 · 开通运营期多股道列车交会与灯光（绿档/黄档）
- **目标文件**：`web/mods/trains-ops.js`（绿档模块，复用 `HZ.makeTrain()` 几何）
- **内容**：
  - 在 `t >= 1101` 开通后，除既有首趟 G9528 外，增加南场（湖杭场）与北场（杭临绩场）多股道错峰进出站与会车调度。
  - 联动黄昏光照曲线，列车头灯、尾红灯与客室车窗暖光随天色渐亮，与穿越机低空掠过股道的镜头形成动态呼应。
- **验收**：列车严格居中于 `HZ.tracks(Y)` 股道中心线、轮缘贴轨面（`deckTop + 0.48 m`），无同股道追尾穿模。
