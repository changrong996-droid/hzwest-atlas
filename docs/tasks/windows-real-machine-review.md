# 任务书 · Windows 真机审查（浏览器实看）

**适合**：有本地 Windows 或 Mac 桌面、能开真实浏览器（Chrome / Edge）的智能体。Node 自测与无头 swiftshader 覆盖不到「看得见的东西」。
**目标**：在真机浏览器里逐图看一遍线上图册，交出可执行的问题单——报错、空白图纸、文字重叠或出界、镜头穿地、帧率。只发现问题，不改代码。
**做法**：
1. `git pull`，用线上地址 `https://changrong996-droid.github.io/hzwest-atlas/web/hzwest.html#sheet=<图号>`（本地自测也可用 `python -m http.server` 起静态服务，注意根地址跳转会丢 hash）。
2. 每张图取时间窗内 3 个时刻（起 / 中 / 末），1920×1080 单屏；每题截图存档在自己机器上，不进仓库。
3. 记录：控制台 error 与请求失败；右栏图纸是否画出；左上大数字与图号、日期、天数是否对得上；文字是否重叠、出界、被裁；相机高度是否 ≤ 地面（可从 `window.__pv.cam.position.y` 读）；`requestAnimationFrame` 间隔算帧率（≥55 fps，无 >1 s 卡顿）。
4. 顺手记首屏冷启动耗时（禁缓存）与是否依赖外网 CDN。
**交付**：`docs/audit/<日期>-windows.md`（问题单：图号 · 视口 · 时刻 · 现象 · 复现 · 建议 · 截图文件名），截图不进仓库。不改代码。
**范围**：`D-03` 试点只需 S-501（已在 `docs/audit/2026-11-08-windows.md` 交卷）；后续扩到 S-101 / S-201 / S-301 / S-401 时另起一份问题单，别覆盖旧文件。
