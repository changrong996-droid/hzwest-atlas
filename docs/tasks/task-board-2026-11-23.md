1. 所有涉及主站模块（A/W/V 系列）的分支必须通过 `node tools/hz/check_all.js` 全项绿灯，严禁放宽任何审计规则。
2. 所有短片分支（F 系列）严禁修改宿主 `web/hzwest.html` 与 `web/hzview.js`，严禁篡改 `docs/film/2026-11-23-film-plan.md` 第三节「事实锁定」。
3. 鼓励对 **F2（穿越机航线）**、**A2（室内空间）** 等强审美任务启用 **多路并行挑优**，同一任务允许多位智能体并行提交候选方案与真机 GPU 截图，由委托人择优合入。
