# 任务书 · S-101 地下
**目标**：一屏讲清 365 天地下工程：4 层地下结构（含地铁层）怎样一层层往下挖、往上做。
**数据**：活动 `found`（0–365）。地铁层槽：|x|<199.2、|z|<13.2、y∈(−9.2, 0)（见 hzview.js 的 UG 常量）。
**大数字**：挖到的深度（m）或已完成的地下层数。
**图纸**：横剖面（支护、各层板、地铁层），随时间填充墨线剖面线。
**镜头**：低角度看基坑；绝不能从地面以下看出去看到虚空（当前镜头规则禁止进地下，地铁层入口是另一项任务）。
**交付**：`web/sheets/s101.js` + `tools/hz/check_s101.js`。
**坑**：`found` 只有一个活动，分层节奏要你在模块里按规则拆（先支护、后开挖、逆作或顺作需查公开资料并在注释写来源）。
