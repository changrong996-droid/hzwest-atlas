# 履带吊臂长规则（R10b）· hark-darrio

任务书：`docs/tasks/crane-reach.md`。检查脚本：`node tools/hz/check_crane.js`（默认报告；`--strict` 时有超限即失败）。规则落地改 `hzseq.js` 由 hark-cr 做。

## 规则

每次履带吊吊装（`p.crane === -1`）：

    吊距 R = 站位 p.crawl 到构件中心 p.c 的水平距离
    W × 1.1 ≤ 额定起重量(机型, R)        （1.1 = 吊钩、索具；额定表本身已含 75% 倾覆储备）

不满足 → 先在 R 上限圈内换站位；圈内找不到净空站位 → 换大一级机型；1000 t 级也不够 → 记违例（与 R10 无站位同级）。

建议 `HZ.assignCranes` 的站位搜索改成：搜索半径 = 该构件 W 对应的 R 上限（650 t 级，见下表 3），而不是现在的 dz ±150 m / dx ±60 m 网格；出圈才升 1000 t 级。

## 表 2 · 单吊重量 W（推算，待 hark-cr / 委托人校）

| 类别 | 判据 | W |
|---|---|---|
| 构件自带吨位 | `p.tons` 存在（如 mast） | `p.tons` |
| 现浇混凝土 | mat = conc / plat / found / ym | 8 t（3 m³ 吊斗满斗约 7.5 t + 斗重；钢筋笼、模板同量级） |

| 钢构件、临时支架分段 | mat = steel / red，且无 `p.tons` | 20 t |

HZ 的构件盒是成段几何（如一块楼板 9300 m³），不是一钩的重量，所以按类别取一钩。`p.t` = `p.tons × 2.5` 不是一钩重量，未用。
