## 1. 目的

用我们 Blender 管线出的「骨架图」（同一机位的深度 / 法线 / 线稿 / 白模 / 分割）锁住几何，由你那边的扩散模型（ControlNet 之类）补成照片质感，作为宣传页 S-401 一屏的右图。**几何以骨架图为准**：屋面轮廓、四朵云起伏、十字采光顶位置不得被模型改动；模型只补材质、光线、环境。

镜头：S-401 屋面合拢，模型时刻 t=756（2021-10-12，金属屋面刚铺完，光伏尚未铺），相机在东南上空约 530 m，40 mm 镜头（36 mm 画幅），看向屋面中心。相机矩阵与近远平面在每张图的 `_cam.json`。

## 2. 控制图清单与取用位置

两套：**detail=on（优先用）** = 在页面同源几何上自动加了棱边倒角、0.5 m 直立锁边肋、采光顶竖梃、网架圆管 + 螺栓球；detail=off = 页面原几何。同一机位，像素对齐。

## 3. 推荐 ControlNet 组合与权重

| 单元 | 输入 | 权重 | 起止 | 备注 |
|---|---|---|---|---|
| 深度 | `s401_depth(_16)` on | 0.6–0.8（先 0.7） | 0 → 1.0 | 锁大体量与透视 |
| 线稿 | `s401_line_inv` on（lineart / canny 类） | 0.5–0.7（先 0.6） | 0 → 0.8 | 锁屋面轮廓、四朵云等值线、十字采光顶、站台边 |
| 分割（可选） | `s401_seg` | 0.3–0.5 | 0 → 0.6 | 重映射后再用；用来防止玻璃 / 金属串色 |
| 法线（替代深度） | `s401_normal_cn` | 0.5–0.7 | 0 → 1.0 | 有 NormalBAE 模型时可替换深度，四朵云起伏更稳 |

- 分辨率：1024×576（SD1.5 可用 768×432 再放大）。步数 30 左右，CFG 5–7。
- 可选 img2img：以 on 版白模或实景渲染（`~/blender-v2/out/d1/roof_real.png`）作初始图，重绘幅度 0.55–0.7。
- 先出 2–4 张，按第 5 节验收，选 1 张。

## 5. 验收

1. **轮廓偏差**：把成图与 on 版白模（同为 1024×576）50% 叠图看；再用分割图里「屋面金属板 + 采光顶玻璃」两类的并集作屋面掩码，与成图的屋面轮廓（手描或自动分割均可）比，屋面掩码 IoU ≥ 0.95，屋面外轮廓偏差 ≤ 4 px（1024 宽）。十字采光顶中线偏差 ≤ 4 px。四朵云的明暗起伏方位与白模一致（不得多出 / 少掉鼓包）。
2. **内容**：无人物、无文字、无水印；屋面是银灰直立锁边金属板，云缝是玻璃；无塔吊。
3. **标注**：右下角固定角标「AI 生成 · 非实拍」，不可去掉；图下小字「依据 S-401 屋面合拢，模型时刻 t=756；Blender 骨架图 + 扩散模型生成」。
4. **交付**：按 `docs/proposals/promo-page.md` 体系：图不进仓库，成图外链写进该文件「样图」一节，注明提示词来源（本交接单）与所用 ControlNet 组合 / 权重 / 随机种子；叠图核对结果一并附上。委托人看样图后再定是否做页。

## 6. 已知问题

- 屋面檐口一圈有锯齿状破面（页面屋面网格边缘本身的问题，细节加强没处理）：AI 补图时容易被放大，验收时留意；轮廓偏差按大轮廓算。
- 深度图在屋面范围内对比度低（530 m 外 3.5 m 起伏），四朵云要靠线稿 / 法线锁。
- 法线约定未用真模型核对（见第 2 节）。
- detail=on 的锁边肋只有约 2 px 一条，法线图里有轻微摩尔纹（已用 64 采样平均）；若模型把它读成条纹噪点，改用 off 版法线。
