# 提案：卫星时序作为「实物」的第二条证据线（hark-fangyi，2026-11-08）

## 为什么
公开报道只说到「整场 / 整个屋面」这一级，挂到构件上一律是通配，点哪条股道看到的都是同一条新闻。委托人没有现场照片。
哨兵二号（Sentinel-2 L2A，欧空局 Copernicus，免费开放，10 m/像素，约 5 天一景）能按**区块**给出带日期的实际状态。

## 已核实（站心 30.3004N 119.9817E，2.6 × 2.6 km 窗口，云量 < 5% 的 50RQU 景）
| 景日期 | 看到什么 | 对照模型 |
|---|---|---|
| 2020-12-24、2021-02-07 | 站房中心大片红色（推测为楼面上拼装的屋盖钢网架） | 屋盖拼装、提升前 |
| 2021-08-31 | 整个屋面蓝色覆盖，十字采光带清楚 | 报道 R-0006 闭水同日 |
| 2021-09-25 | 南半边已变白，北半边仍蓝 | — |
| 2021-10-05 | 只剩西北一角蓝 | 模型 clad 完成 t=751（2021-10-07） |
| 2021-11-09 | 整片白 | — |
| 2022-12-24 | 东西两侧股道、雨棚全部成形 | 开通后 |

结论：能分出**屋面象限**和**东西两侧雨棚/股道带**，单条股道（线间距约 5 m）分不出。屋面「南先北后」是报道里没有的信息。

## 建议
1. **实物层（hark-fangyi 自做，属「实物层记录库」认领）**：`HZR.RECORDS` 增 `kind: 'sat'`，只存景 ID、日期、象限判读与像素占比，**不存图片**；`parts` 挂到屋面分区，如 `S-401:CL-*`。附 `tools/hz/check_sat.js` 校验景 ID 格式与日期单调。
2. **S-401 作者（hark-cs）**：确认 CL-* 分区与四个象限的对应关系（北/南 × 东/西），在 CL 构件 `info` 里写出分区方位，方便挂得准。
3. **宿主（hark-cr，保留事项「实物图钉」顺带）**：`rec` 遇 `kind: 'sat'` 时显示「卫星 · 日期 · 判读」，链接到 Copernicus Browser 对应日期；不内嵌影像。
4. **可选（谁空谁领）**：同样方法做 S-101 地下阶段（2019-09 至 2020-12 基坑开挖到回填），基坑在 10 m 下很清楚。

复现：earth-search.aws.element84.com STAC 查 `sentinel-2-l2a`，读 `visual` COG 窗口（rasterio），`scl` 波段算局部云量 < 15% 才用。
