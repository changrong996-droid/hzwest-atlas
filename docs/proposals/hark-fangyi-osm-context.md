# 提案 · 城市远景层：把杭州西站放回真实的杭州（hark-fangyi，2026-11-22）

## 一句话
用 OpenStreetMap 现状 + 哥白尼 30 m 地形，在主页面三维里把站房周边约 6.6 × 4.6 km 的真实城市、32 × 24 km 的山体铺出来，替换现在的程序化随机城市与示意远山；站房仍是我们自己的模型，时间轴照旧由宿主驱动。

## 为什么做
- 委托人 11-20 的判断：逐件对照现实意义不大，更想要「谷歌地球」式的整体感——看清西站与云城、未来科技城、地铁 3 / 19 号线、合杭（湖杭）铁路、余杭西南丘陵的关系。
- 现在 `hzview.js` 的 `CTX.city` 是 2600 个随机盒子、`MTN` 是示意山，一拉远就露馅；真实路网和楼群能让「这座站在城市里是什么分量」一眼看懂，也给后面的规划叙事（TOD、换乘）留底座。
- 先做独立页验证（站房用本仓库模型导出、对齐、时间轴、地形），委托人看过认可后，再收成模块走正常接入。

## 思路与做法
1. **数据只用开放许可**：城市 OSM（ODbL 1.0），地形 Copernicus DEM GLO-30（可再分发，署名写进数据 `src` 与模块注释）。不入卫星 / 商业影像。
2. **对齐**：经纬度 → 站心局部米（30.3004N, 119.9817E），量 OSM 合杭线方位约 4.3°，模型绕站心转 4.3°、东移 10 m 后，模型 20 股道两端正好接上 OSM 国铁，地铁 3 / 19 号线从站房正下方穿过。OSM 里落在站房模型包络内的建筑、站内段国铁剔除，避免和模型打架。
3. **画法跟主站语言走**：建筑纸白体块 + 墨线轮廓，路白、水浅蓝、绿地浅绿，全部 `MeshBasicMaterial` 不吃宿主灯光——宿主墨线遍会关掉日光，用受光材质会整片发黑（本地实测过）。
4. **地形**：±16 × ±12 km、80 m 网格；DSM 平原 < 25 m 的起伏（楼、树）压掉；城区框（±3.3 × ±2.3 km）内压到 −1.5 m，让宿主地面盖住，框外 1.5 km 平滑抬起。坡面明暗按宿主日光方向预烘焙进顶点色。
5. **和工期联动**：合杭高铁、地铁 3 / 19 号线开通日（第 1101 天，2022-09-22）前画浅灰预留线，之后上色；其余城市为 2026-11 现状（OSM 没有建成年份，不硬编）。
6. **标注**：只挂地铁站和 60 m 以上楼名，镜头距原点 > 900 m 才显示，近景不干扰宿主引线。

## 接入要宿主做的（接口请求，等 hark-cr 定）
1. `web/hzwest.html` 在 `mods/tour.js` 之后、`hzview.js` 之前加两行：`mods/osmctx-data.js?v=1`、`mods/osmctx.js?v=1`。
2. **模块声明替换**：`HZ_MODS` 建完后，若有模块声明 `replaces` 含 `'ctx.city'`，把 `CTX.city` / `CTX.lines` 从 `LITONLY` / `INKONLY` 摘掉并隐藏；含 `'mtn'` 同理摘 `MTN`。本地测试补丁约 1 行，放在 `function modOff` 前：
   ```js
   { const RP = new Set(MODS.flatMap(m => m.replaces || [])); if (RP.has('ctx.city')) { for (const o of [CTX.city, CTX.lines]) { o.visible = false; for (const L of [LITONLY, INKONLY]) { const i = L.indexOf(o); if (i >= 0) L.splice(i, 1); } } } if (RP.has('mtn')) { MTN.visible = false; const i = LITONLY.indexOf(MTN); if (i >= 0) LITONLY.splice(i, 1); } if (RP.size) ctl.maxDistance = 16000; }
   ```
   `CTX.lines` 里还有 50 m 绘图网格和施工围挡虚线，若想保留，建议把它们拆成单独对象，只让随机楼的轮廓随 `ctx.city` 让位。
3. **拉远上限**：`ctl.maxDistance` 现为 4200，看不到城区全貌和远山；建议 osmctx 在场时放到 16000（相机 far 已是 40000，够）。
4. `tools/hz/check_all.js` 清单加 `check_osmctx.js`（约 0.5 s）。
