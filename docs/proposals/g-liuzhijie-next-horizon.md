## 二、纵深演进：先把西站做透，再让周边远景「长出来」

不急着跨到其他超级工程，也不做多余的元叙事噱头——现阶段最有价值的是沿着**「站内细节做深 → 站外远景长开 → 规则可拨动」**三条线，把杭州西站本身打磨成一个真正站城一体的活图册：

### 1. 先把西站自身细节按「规则 + 模块」打磨透
- 延续 `actors.js?v=2` 纸白遮挡 + 结构墨线精修的思路，把目前还偏简略的视觉薄弱项逐块做实：
  - **云门成品态建模**（替代当前 S-000 的示意线型，补齐门洞、幕墙分格与墨线语汇）；
  - **S-301 提升段钢绞线与屋盖 4° 转动近景特写**、**剖切看云谷采光穿透至地铁层**；
  - **双层景深**：主屏严守极简墨线，按需下钻——外行看到复兴号/人高/重量与真实提升速度的直觉尺标，内行点构件可顺着因果链查到前置工序、吊机核算与实拍对照。

### 2. 让项目周边的远景随时间轴逐步扩大、「慢慢生长出来」
- 目前西站主体精致，但周边仍是空白底图，少了杭州西站最核心的**「站城融合（云城 TOD）」**气质。
- 可以用极轻的**淡墨线轮廓 + 分圈层 LOD（外围纯简笔、不抢主体戏）**，以独立 `HZ_MODS` 模块让周边环境按真实建设节奏向外生长：
  - **第一圈（交通接驳）**：东西向铁路高架延伸、落客高架匝道、地下地铁走廊与站前广场，随主体施工同步拉通；
  - **第二圈（站城综合体）**：南北综合体（金手指 / 金钥匙等云城核心塔楼）与周边主干路网，在站房封顶与开通前后以极淡墨线逐栋长出；
  - **第三圈（远景天际线与地形）**：远处的余杭山体等高线与城市街区肌理，提供开阔的空间纵深感。
- 既大幅提升拉远镜头与首屏导览的震撼度，又能严格按距中心距离做淡出和面数控制，不影响帧率。

### 3. 从「历史回放」延伸到「反事实工程沙盘（What-If）」
- 依托现成的规则引擎（`hzseq.js` + `hzrel.js`），在把西站做透的基础上，给信息卡加 2–3 个极轻的「如果」交互开关：
  - *如果抽掉某根临时支撑* → 哪些构件失去支承链、自检跳红（借封单后第 2 周的「试拆临时支撑」直接落地）；
  - *如果履带吊限流再收紧* → 关键链与总工期如何实时拉长。
- 让观众不只是看回放，而是亲手拨动规则，直观体会「为什么必须这样造」。

## 三、节奏与防臃肿原则
- **先内后外，一步一验证**：先收口近期 4 项与西站内部薄弱细节，再以独立 `HZ_MODS` 模块逐圈扩展周边远景（外圈只用淡墨线和少量实例化几何，不背重贴图）；等西站本身与周边生长体系都跑顺了，再考虑抽离通用引擎去套其他超级工程。
- **不破坏主屏底线**：所有新增交互进信息卡或独立模块，不改共用文件边界，全量走 `check_all` 门禁。
