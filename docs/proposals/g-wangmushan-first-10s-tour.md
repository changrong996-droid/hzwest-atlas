## 2. 体验结构：前 10 秒单图慢播起手 + 后 50 秒内部穿越剧场

### 2.1 时刻表达规范（不写死天数）
`TOUR_BEATS` 剧本一律使用 **`<活动key>@<0..1比例>`**（运行期由 `HZ.K[key]` 换算 `start + ratio * (end - start)`），以后排程校准无需改剧本。当前基线真值参考：`frameS/N` 365–405、`floorS/N` 565–590、`lift1..3` 636–649、`wlift` 659–663、`clad` 693–755、`pv` 755–785、`open` 1101。

### 2.2 前 10 秒：单图 `S-000` 缓慢生长起手（0s → 10s，零切图）

开场进入 `body.tour-intro` 精简态：临时隐藏 `#calc` 审计日志与 `#lede` 长句，屏幕只留 **3D 墨线画面 + 右侧实时图纸 + 左上角唯一大数字 + 底部 1 行人话字幕（≤18 字）**。

- **全程停在 `S-000` 一张图**（不调 `setSheet`，避免清焦点、停播放与节奏过急），严格贴合委托人「缓慢播放」要求：
  - **0–5s**（`frameS@0.35 → floorS@1.0`，约 `t = 379 → 590`）：直接从地下已出地面、框架柱与候车层正在生长的骨架态缓播起手，镜头从南侧中空缓慢贴近工作面推进；左侧朱砂红构件向上生长，右侧图纸同步重绘。字幕：`3 年工期 · 1906 个构件按力学先后自己长出来`。
  - **5–10s**（`asm1@0 → wlift@1.0`，约 `t = 604 → 663`）：继续在 `S-000` 缓慢推进至屋盖网架拼装与整体提升到位，镜头顺工作面轻柔拉升，让陌生人在前 10 秒内安静看清「整座站房怎么在图纸陪伴下长出屋顶」。字幕：`1.3 万吨屋盖抬升就位 · 随时拖动或点图纸接管`。

### 2.3 第 10–60 秒：建筑内部穿越与核心魔术示范（未被打断时自然续播）

观众前 10 秒未被吓跑且未触碰屏幕时，进入舒缓的 50 秒穿行与功能演示，把隐藏杀手锏逐一端出：

1. **10–22s · 云谷低空穿行（`S-000`，`frameS@0.5 → floorS@1.0`，约 `t = 385 → 590`）**
   - **开洞与避让实查结果**（已用 `HZ.make()` 遍历全量 `p.bb` 验证）：候车层 `floorS` / `floorN` 在 `|z| < 14` 处为 **0 块重叠（确实完全开洞）**；但 `t = 604–646` 有中区落地胎架 `jigL2`（`z ≈ ±7`），`x = ±260` 有两台塔吊 `crane`。
   - 因此穿行轨严格限定在 **`|z| ≤ 14`、`|x| ≤ 220`、`y: 28 → 18 m`** 且 **`t < 604`**，全程 0 障碍，贴近 `actors.js` 墨线工人与车辆建立巨物比例尺，并纳入 `check_cams` 逐帧扫描。
2. **22–36s · `S-301` 图模双向跳转 + 屋盖 4° 旋转微距（`lift1@0 → lift3@1.0`，真值 `t = 636 → 649`）**
   - 切至 `S-301`（`setSheet('S-301')` 后由 `tour` 接管缓播），在右侧千斤顶平面图 `J23`（`x=115, z=46.5`）亮起朱砂红点击涟漪，调用 `focusLifter(22)` 让 3D 镜头俯冲锁定提升器与屋盖下弦夹缝，演一遍「点图纸 → 3D 飞过去」。
   - **口径明确**：字幕写 `实际 206 台千斤顶同步发力 · 右图 32 组代表点位均可点选`，避免误导观众以为画面里能点到 206 个点。
3. **36–48s · `x = 39 m` 一刀剖切透视五层（`S-301`，`wlift@0.25 → wlift@1.0`，真值 `t = 660 → 663`）**
   - 调用宿主 `focusCut(1)` / `setCut(1)`，配合斜俯视机位（规避 GPU 审计 #12 侧视看不出封面的问题）缓慢扫过剖切面，看穿地下地铁 → 承轨层 → 候车厅 → 屋盖网架。
4. **48–60s · 屋面封闭、光伏与开通亮灯收官（`S-000`，`clad@0 → open@1.0`，真值 `t = 693 → 1101`）**
   - 展示屋面封闭与 1.5 万 m² 光伏铺设，末尾调用 `opt({ mode: 'lit' })` 触发墨线褪去、黄昏暖光亮起与列车进站。
   - **前置依赖注记**：目前「屋面南先北后」尚在等黄档补丁合入 `hzseq.js`，首版此段只客观展示屋面与光伏闭合，待该补丁合入后再追加南先北后字幕强调。

打断或播完后恢复完整 HUD 与 9 个 `S-xxx` 图号；底部控制条上方仅保留 **2 个核心快捷胶囊**（+ 重播小图标），其余留待第二轮：
