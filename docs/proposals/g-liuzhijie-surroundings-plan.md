# 规划与并行任务书：杭州西站周边远景生长（surroundings 脚手架，g-liuzhijie，2026-11-22）

## 1. 背景与目标
当前 `web/hzview.js` 已有 `16000 × 16000 m` 地面、远山（`MTN`）以及 `1500 m` 以外的伪随机城市背景（`CTX`），但 **`300 m ~ 1500 m` 这一圈最显眼的中景完全空白**（站外铁路延伸线贴地 `y = 0.3 m`，南北两侧与疏解高架均为空地）。

本规划搭建一套极轻、零冲突的**分层注册脚手架**，让杭州西站周边的交通骨架、南北综合体（云城 TOD）与中景街区肌理**随时间轴真实生长**，并拆成 4 个互不冲突的公开子任务，供任意云端沙盒智能体并行认领推进。

---

## 2. 坐标系与硬边界
- **坐标系**：`x` 为东西向（站房主跨 `|x| ≤ 225 m`，引桥至 `±650 m`），`+z` 朝南（云门 `z ∈ [178, 238]`），`-z` 朝北，`y = 0` 为地面标高。
- **主站区禁入包络（机检强制）**：任何周边图层线段均不得闯入主站房与云门范围 **`|x| < 645 && z > -245 && z < 245`**；外包络须落在 `|x| ≤ 2500, |z| ≤ 2500, y ∈ [-30, 420]`。
- **视觉层级（墨线淡出，不抢主体戏）**：
  - `ring: 1`（交通骨架，透明度 `0.36`）
  - `ring: 2`（南北综合体核心地标，透明度 `0.24`）
  - `ring: 3`（中景街区肌理与远景过渡，透明度 `0.14`）
- **显隐规则**：仅在 `S-000`（总图）与 `S-501`（开通）显示，施工分图（`S-101 / S-201 / S-251 / S-301 / S-401`）自动隐藏，不干扰分图特写。
- **性能底线**：全部图层合并进 3 个按 `tOn` 升序排列的 `THREE.LineSegments` 缓冲，每帧只做 `O(log N)` 二分更新 `drawRange`，无头检查断言 `update` 平均耗时 `< 1 ms`。

## 3. 脚手架与图层注册合同（零冲突并行）
- **聚合器**：`web/mods/surroundings.js`（注册进 `window.HZ_MODS`，`id: 'surroundings'`，支持 `opts.clip` 剖切平面）。
- **子图层写法**：每个并行任务只新增一个独立文件 `web/mods/env/<图层名>.js`，向 `window.HZ_ENV_LAYERS` 推入一个对象：
  ```js
  (window.HZ_ENV_LAYERS = window.HZ_ENV_LAYERS || []).push({
    id: 'roads-ramps',          // 唯一小写短名
    name: '留石高架与疏解匝道',
    ring: 1,                    // 1 / 2 / 3（决定墨线透明度）
    build(HZ, api) {
      // api.add(tOn, x0, y0, z0, x1, y1, z1)
      // api.addPhased(t0, t1, x0, y0, z0, x1, y1, z1, step)
      // api.box(t0, t1, x0, y0, z0, x1, y1, z1, step)
    }
  });
  ```
- **自动校验**：`node tools/hz/check_surroundings.js` 自动扫描 `web/mods/env/*.js`，校验图层合同、单调生长、禁入包络、`opts.clip`、分图自动隐藏与 `< 1 ms` 性能——新增图层**无需改检查脚本**。
