# 提案：图纸「关键时刻效果图」（AI 生成层）

提案人：hark-cs · 2026-11-09 · 委托人已同意方向

## 1. 为什么做
图纸要专业功底才看得懂。效果图回答一句话：**「这一刻工地看上去是什么样？」**
它不是证据，也不追求逼真或和模型逐像素一致（委托人 11-09 定调：扩散模型本来就不会完全一样，硬追一致是本末倒置）。它展示的是：**这套图纸数据能「长」出什么。**

## 2. 用在哪里（按优先级）
1. **图纸页内的关键时刻条**：每张图纸 3–4 张，拖动时间轴经过该时刻时，右栏角上出一张小图，点开看大图。给看不懂图纸的人一眼看懂。
2. **宣传页 / 3 分钟导览**（D-17 promo-page 体系）：同一机位按时间串成「屋面长出来」的一组。
3. **分享卡片**：链接预览图。

## 3. 怎么生成（可复现）
- 几何和时刻全部来自图纸数据：`blender/v2/ctrl.sh timeline <t> <名> W H` 出白模 + 深度图（同一组同一机位）。
- 生图只喂白模 + 深度，阶段与材质写在提示词里；不喂分割图（色块会漏进成图）。
- 每张固定角标「AI 生成 · 非实拍」，图注写：图纸号、模型时刻 t、对应日期、阶段一句话。

## 4. 验收（只看三条）
1. 看得出是哪个阶段（如「网架全裸」「采光顶在装」）。
2. 主要构件位置大体对得上（屋面轮廓、十字采光顶、塔吊大致位置）。
3. 同组几张机位一致、风格一致，放在一起像一组。
不打分、不量像素偏差。

## 6. 需要宿主做什么（接口请求，hark-cr）
- 插件可选导出 `keyframes: [{t, img, caption}]`；宿主在时间轴上画小刻度，播放/拖动经过时右栏角出缩略图，点开大图。
- 图片放哪：建议 `web/fx/<图号>/<t>.webp`，每张 ≤150 KB（约 1280 宽）；若仓库不收图，就外链（需定一个稳定图床）。**请 hark-cr 定。**
- 宿主默认关闭，URL 加 `#fx=1` 打开，不影响现有页面测试。
