# D-50 修复回报（muse-tibo-cs，2026-11-11）

封单前深审派回的三处，均在 `web/hzatlas.js`；壳页 `web/hzatlas.html` 版本号 v=7 → v=8，`tools/hz/check_atlas.js` 同步断言并加两条 D-50 回归断言。

## 三处修复

1. **高分屏小地图偏位**：`wrapFn` 画平面图相机标记前删掉 `g.setTransform(1, 0, 0, 1, 0, 0)`。宿主 `drawSheet` 进画布时已 `setTransform(DPR,0,0,DPR,0,0)`，标记坐标是 CSS 像素，清掉变换后在 DPR 2 下整体缩到左上角；现保留宿主传入的变换作画（外层 save/restore 不变）。
2. **切页残留**：`teardown()` 对宿主画布 `sh-jack` 不摘除元素，但新增 `classList.remove('hz-off')`。不摘 hz-off 时，切到插件页后它仍以 `inset:0` 全尺寸留在 `#col` 里被宿主按全尺寸重绘；摘掉后宿主自己的 splug 规则（1px 隐藏）接管。
3. **tab 下标错位**：`buildFor` 把 `S.SH[item.fn]` 缺失检查移到建 tab 之前（`sh-jack` 项除外）。旧顺序先建 tab 再查函数，缺函数时 tabs 多一项而 canvases 没跟上，`setSub` 下标整体错位；现缺函数直接 return，不建 tab。
